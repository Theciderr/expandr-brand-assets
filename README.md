# ExpandR brand guidelines

Version 2.0 · 10 October 2026. This replaces version 1.0 (the three-part R with the blue leg), which was rejected.

ExpandR is a B2B development and technology studio: business websites, lead-generation systems, workflow automation and software implementation.

## Logo

The wordmark is the logo: "expandR" in heavy, wide lowercase with a capital R. The d and the R share one stem.

- It is artwork, not typed text. Always use the files; never retype it.
- Clear space: a margin as tall as the letter x on every side.
- Smallest size: 96 px wide on screen, 25 mm in print. Below that, use the icon.
- Drawn from the open-licence typeface Anybody (width 135, weight 850) with a custom joined dR.

## Icon

Three quarter-circles turn around one point, each larger than the last (the "pinwheel").

- Use it alone wherever a square is needed: browser tab, profile picture, app icon.
- It never sits beside the wordmark.
- At 24 px and below, use the small-size files, which have wider gaps.

## Colour

| Name | HEX | RGB | Role |
|---|---|---|---|
| Black | `#0A0A0A` | 10 10 10 | Main ground and type |
| White | `#FFFFFF` | 255 255 255 | Main ground and type |
| Signal orange | `#FF4F00` | 255 79 0 | The one accent |

- One main orange element per page or screen: a button, a corner tile or a thin edge. The small icon may also be orange. The profile picture is orange.
- Type on orange is always black (6.0:1). White on orange is 3.3:1 and is not used for text.
- Orange on black is 6.0:1. Orange on white is 3.3:1: icon and large type only.
- Working greys, added during production and not yet reviewed: `#5E5E5C` for secondary text, `#F2F2F0` for page backgrounds.

## Type

| Role | Typeface | Settings |
|---|---|---|
| Headline | Anybody | Width 108, weight 760, line height 1.04, sentence case |
| Label | Anybody | Width 110, weight 620, capitals, letter spacing 6%, 11 to 12 px |
| Body | Hanken Grotesk | Weight 400, line height 1.5; weight 600 for emphasis |

Both are free under the SIL Open Font License and are on Google Fonts.

## Do not

- Retype the name or pull the d and the R apart.
- Place the icon beside the wordmark.
- Set white type on orange, or colour the wordmark orange.
- Use more than one main orange element on a page or screen.
- Stretch, outline, rotate, or add shadows and gradients.

## Files

| Use | File |
|---|---|
| Logo on white or orange | `expandr-wordmark-black` (SVG, PNG) |
| Logo on black or photos | `expandr-wordmark-white` (SVG, PNG) |
| Icon, 32 px and larger | `expandr-icon-black`, `-white`, `-orange` |
| Icon, 24 px and smaller | `expandr-icon-small-black`, `-white`, `-orange` |
| Profile pictures | `expandr-avatar-orange`, or `-black` on dark interfaces |
| Browser tab and app tiles | `favicon/`: `favicon.ico` (16, 32, 48), `favicon.svg`, PNG at 16, 32, 48, 180, 192, 512 px |
| Reference | `brand-board/` (PNG, PDF) and `mockups/` (website, social profile, proposal and invoice) |

Use SVG wherever it is accepted and PNG elsewhere. PNG files have transparent backgrounds, except the profile pictures.
